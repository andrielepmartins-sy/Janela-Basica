# Janela Básica com Tkinter

Este repositório contém os exemplos desenvolvidos durante as aulas de Desenvolvimento de Sistemas, utilizando a biblioteca **Tkinter** para criação de interfaces gráficas em Python.

O objetivo é registrar os conteúdos estudados em aula e servir como material de consulta durante o aprendizado.

## Conteúdo

Durante esta atividade foram abordados os seguintes conceitos:

- Criação da janela principal (`Tk`)
- Configuração de título, tamanho e posição da janela
- Centralização da janela na tela
- Alteração da cor de fundo
- Configuração de redimensionamento
- Definição de tamanho mínimo e máximo
- Configuração de transparência
- Criação de rótulos (`Label`)
- Criação de botões (`Button`)
- Manipulação de eventos
- Exibição de caixas de diálogo (`messagebox`)
- Captura de dados com `Entry`
- Exibição de imagens utilizando `PhotoImage`

## Organização dos meus arquivos

| Arquivo | Descrição |
|---------|-----------|
| `JanelaPrincipal.py` | Criação e configuração inicial da janela. |
| `PosiçãoDaJanela.py` | Posicionamento e centralização da janela na tela. |
| `Redirecionamento.py` | Configuração de redimensionamento, tamanho mínimo, máximo e transparência. |
| `Button.py` | Implementação de botões e eventos de clique. |
| `CapturandoDados.py` | Leitura de informações digitadas pelo usuário. |
| `img.py` | Inserção de imagens na interface. |
| `VisãoGeral.py` | Exemplo reunindo todos os conceitos apresentados na aula. |
